# 账本事件 id 迁移记录（2026-10-13）

> 本文件记录一次**对既有账本行的 id 变更**，供第三方对账。变更经维护者裁定（2026-10-13「重生成」），非手改。

## 为什么

`docs/bounty/ledger.json` 的 13 条早期事件（2026-10-12 批次）的 `formula` 快照只写了
`{"kind": "complete", "round": 1}`，**缺 `rule` 字段**。`scripts/bounty_board.py` 的
`rescore()`（复算器）按 `formula.rule` 分派，缺该字段即报 `unknown rule None`，
⇒ 这 13 条**无法被独立复算**，与 `README.md`「第三方可复算」的承诺不符。

## 做了什么

用**权威单点** `quality_delta(base, rounds=2)` 重生成这 13 条的 `formula`，
与其余 53 条同款：追溯性结算、无轮次证据 ⇒ 中性点 `round=1` ⇒ `Δ == base`。
`delta` 一律未变（13 条原本即 `delta == base`，重算后逐条断言相等）。

## 副作用：事件 id 变了
