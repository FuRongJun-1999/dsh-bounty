## 二 两条轴不可互推（本表最重要的一条读法）

**难度（base）与影响等级（IMPACT_GRADES）互相独立，且不可由一方推出另一方。** 本批就有两个反例：
- **#7**：改动形态是「一个证据块 + 补丁方向」（**没有改代码**），若按改动量看它最轻；但它的影响是 **S 级**——默认装机即可触发的**不可逆数据删除**。
- **#1**：2719 行的平台设计（**篇幅最大**），但它是文档，影响为 **C 级**。

⇒ 这正是「价值评价」不能被难度替代的原因。**双轴记录，合成交由使用者。**
