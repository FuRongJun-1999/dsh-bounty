## 二 论证：为什么记忆系统优先

1. **记忆是所有能力的前置**——检索、推理、协作、信任都建立在「记得住、找得到、改得对」之上。
   **本站活证据**：**#7** `verify(falsified)` 绕过删除闸 ⇒ 一次调用**永久删掉一条记忆**、`restore()` 找不回；**#9** 审核接受后有效期丢失 ⇒ **过期记忆仍被召回**。
2. **行业用资本单独定价**——依据 1–4：境内外皆有独立记忆公司拿到千万到亿美元级融资、境内头部估值数亿元；下游市场到 2031 年近三百亿美元。
3. **第三方口径支持**——依据 8：**90% 的生产失败源于上下文管理失当**（而非模型能力）。
4. **本站已有可复跑的收益**——#2 证据保留 **17.6 → 29.6**；#8 hit@10 **0.076 → 1.00**；#5 625 题 **0.979**。

**对冲（依据 10）**：服务端记忆形态**至少有一家头部在退潮** ⇒ 优先不等于必胜，须以**多宿主 ＋ 可复算 ＋ 责任**立身。

## 三 论证：为什么理论与算法「资源不限」

1. **算法是乘数，不是加数**——一份算法改进被**所有下游复用**：边际成本 ≈ 0，边际收益 = 全站。
2. **瓶颈在算法层，不在工程层**——**#3** 发现**判分链自身**有 3 处缺陷（静默通过／越权改判／除零崩溃）：**量具错了，所有评测结论都错**；工程手段发现不了「量具不可信」。
3. **理论结论可独立复算** ⇒ 可信上限高、验证成本低——#5 **零 LLM 判官**；#2／#6 **定点变异 9/9**；#7 三条变异各自转红。

## 四 边界（三条硬约束）

1. **不合成单一价值分**——合成需要权重，而**权重是使用者侧的决策**。
2. **不出现金额字段**——**资金发生在站外；本站只做评价与产出可换算的维度**（使用者按自己的资金与权重结算，本站不碰钱）。
3. **不固化权重**——站内不得出现「某项目更值钱」的数值表达。

## 五 可复算判据

| # | 判据 | 检验 |
|---|---|---|
| **V1** | 向量可复算 | 只给标签表 ＋ 事件表 ＋ 交付元数据，第三方手算某人的完整向量 ⇒ 与站内一致 |
| **V2** | 资金在站外 | 输出**不含任何金额字段**；资金结算发生在站外，本站只做评价 |
| **V3** | 影响等级留痕 | `impact:*` 必须带判定人与依据；无依据不可写入 |

| **V5** | 测评独立性 | 评分类交付的判据须含「**竞争产品可在同一条件下胜出**」的检验；只证明自家优秀者不计入高影响等级 |
| **V6** | 利益关系公示 | 验收结论涉及**本站自有产品方向**（如记忆系统）的，须显著公示利益关联；**未公示则影响等级不得评 S／A** |
