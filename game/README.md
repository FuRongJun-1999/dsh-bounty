# game —— 角色扮演回合引擎（可运行 · 可测 · 确定性）

对应悬赏 **[#70 角色扮演游戏制作：可运行 + 可测](https://github.com/FuRongJun-1999/dsh-bounty/issues/70)**（hard · 6 分）。

一句话：**一段能被断言的角色扮演回合** —— 起 → 行动 → 结算 → 落痕，全程零随机、零网络、纯 stdlib。

---

## 怎么跑

```bash
python -X utf8 game/run.py --demo                 # 跑一段完整回合（退出码 0）
python -X utf8 game/run.py --demo --seed 2        # 换剧本（确定性：seed % 剧本数）
python -X utf8 game/run.py --list                 # 列出全部剧本
python -X utf8 game/run.py --digest --seed 1      # 只打印落痕摘要（逐字节比对用）

python -X utf8 tests/test_game.py                 # 正向断言：末行「通过 N / 失败 0」
python -X utf8 tests/test_game.py --mutate        # 定点变异自证：15 条逐条恰好转红
python -X utf8 tests/test_game.py --list          # 只看变异表
```

退出码：`0` = 全绿（或变异逐条恰好命中）；`1` = 有断言失败 / 变异未按预期转红；
**`2` = 用法错误**（`run.py`）或 **ANCHOR-MISS**（守卫件——实现漂移即硬失败）。

### 实测读数（Python 3.12.14 / Windows 首测；3.12.15 / Linux 复测）

| 命令 | 读数 |
|---|---|
| `python -X utf8 game/run.py --demo` | 退出码 **0**，输出含 `[起] [行动] [结算] [落痕]` **四阶段** |
| 同种子两次 `--demo` | `sha256` 前 16 位 = `60FC38FA90588360`（两次**逐字节相同**） |

## 玩什么

一段回合有**四个阶段**，各自在落痕里留标记（守卫件据此断言阶段齐全）：

| 阶段 | 做什么 |
|---|---|
| **起** | 声明剧本与初始状态（`seed` → 剧本索引写入落痕） |
| **行动** | 逐条行动；含前置判定——`倒下` 态不得执行主动行动 |
| **结算** | 扣血 / 治疗 / 状态迁移；每次迁移后判不变量① |
| **落痕** | 写入记忆（幂等重复不重复记）＋ 输出终态与摘要 |

**三个内置剧本**（顺序固定、无随机分支）：

| # | 剧本 | 演示什么 |
|---|---|---|
| 0 | 初次交锋 | 记忆幂等（同一情境连记三次只落一条痕）＋ 攻击扣血 |
| 1 | 负伤撤退 | 连续攻击后奔跑，观察状态与生命值变化 |
| 2 | 救治回稳 | 负伤 → 重伤 → 救治回清醒（**唯一允许回血的路径**） |

**两条核心判据**（守卫件必须覆盖，也是本游戏"可测"的含义）：

1. **角色状态一致性** —— `game/rules.py` 的 `ALLOWED` 是迁移合法性的**单点来源**；
   非法迁移抛 `StateError` 并**点名**来源与目标。两条不变量：
   - ① 未经**治疗类迁移**不得回血（`check_invariant_no_free_heal`）；
   - ② `倒下` 态不得执行主动行动（`assert_active`，点名行动名）。
  - ③ `倒下` ⇔ 生命值 0（`check_hp_state`；构造与每次迁移落定时判定，失败不留半态）。
  - 回血唯一入口：`transition(dst, heal=n)`，只对治疗类迁移放行；`heal()` 裸调一律拒绝。
2. **记忆召回一致性** —— 同一情境**恒**召回**自己**的事实（`Memory.recall`）；
   同一情境写入**不同**事实抛 `MemoryConflict` 并点名情境与两个事实（**不静默覆盖**）；
   未知情境返回 `None`（**不猜测**、不回落默认值）。

## 确定性（验收标准第 5 条）

- **全仓零随机数**：`game/` 下无 `import random`、无 `random.*` 调用
  —— 由守卫件 `C3` 机械断言（遍历源文件，命中即红）。
- `--seed` **不是**随机源：它只做 `seed % len(SCENARIOS)` 的**确定性选剧**，
  且选取结果（索引 + 剧本名）**写入落痕**。
- 故「同种子 ⇒ 同输出」是**逐字节**成立，不是概率成立 —— 由守卫件 `E2`（两次运行比对）
  与 `C1`（同进程两次摘要比对）双重断言。

## 边界（与悬赏「不做项」一一对应）

| 悬赏不做项 | 本交付的处置 | 断言 |
|---|---|---|
| 不做纯前端 / 需联网 | 无前端；**无任何网络调用** | `D2` 遍历源码，命中 `socket/urllib/http.client/requests/httpx` 即红 |
| 不引入第三方依赖 | **纯 stdlib**（`game/` 只 import stdlib 与本包） | `D1` 按 `sys.stdlib_module_names` 白名单判定 |
| 不涉资金 / 内购 | 无相关代码 | — |
| 不采集玩家数据 | **不落任何存档文件**；无 IO | 全包零文件写入 |
| 美术资源用文本 / ASCII | 全部输出为中文文本行，无二进制资源 | — |
| 确定性 | 零随机；种子显式落痕 | `C1` `C2` `C3` `E2` |

**已知不做的事（诚实边界）**：

- 不是完整游戏：只有**回合引擎**与三个剧本，没有地图 / 战斗平衡 / 存档格式；
- 剧本是**硬编码**的（这正是确定性的来源）；扩剧只需往 `engine.SCENARIOS` 加元组；
- 未做国际化（输出为中文，与仓内其余工具一致）；
- 未做性能优化（回合是毫秒级，无优化动机）。

## 目录

```
game/
  __init__.py   包说明（设计目标 · 两条核心判据 · 边界）
  rules.py      状态机 + 迁移表 + 两条不变量      ← 判据①的单点实现
  memory.py     情境记忆（冲突即拒 · 幂等 · 不猜测） ← 判据②的单点实现
  engine.py     回合引擎（起→行动→结算→落痕）+ 剧本
  run.py        CLI（--demo / --seed / --list / --digest）
tests/
  test_game.py  21 条断言 + 15 条定点变异（本仓 tests/ 体例）
```

`run.py` 的落痕摘要（`--digest`）就是可比对的"指纹"：同种子必须完全相同。
