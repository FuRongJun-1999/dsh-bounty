结论

逐项指回读数：①「检索质量 4」由证据 1 的 ②行 hit@10 99.8% 与证据 2 的自然问句诚实下界 hit@10 40.2% 共同支撑——上界与下界差距极大，故不给 5：99.8% 是「给定中文标准关键词」的检索侧上界，README 自己写明「端到端真实水平由 AI 归一质量决定（机械下界 57.6，AI 上界趋近 99.8）」。②「记忆持久 4」由证据 3 的三点结构性表述支撑（写入三闸门＋committed、仅显式 forget 可删、派生物可重建）；给 4 而非 5，因这三点是设计表述而非持久性基准读数。③「注入预算」＝未取得读数：README 未提供任何 token／字节用量读数，故记 null、进 unmeasured_dims，不参与任何合计（见 unmeasured_dims）。④「隐私与本地性 4」：README 声明纯词面、零重依赖，并明确不做语义向量嵌入（避免引入嵌入模型依赖与索引体积）；未给 5 因本机未跑该插件自己的入口（未安装、源码仓本轮未离线取全），该维度的 repro 不成立。⑤「可验证性 4」由基准数据随仓公开 ＋ 第三方独立验证报告共同支撑；未给 5 因本机未跑该插件自己的运行入口（证据 4 只是本站证据链探针）；但该报告同时给出了批评，见 boundary。

边界 · 不适用条件

不适用条件：①本条检索读数只在自建 locomo-zh-500 语料上成立——换语料需重跑，README 未声称跨语料泛化。②99.8% 依赖查询已被归一为「中文标准关键词」；LLM 归一环节本身的质量未被单独评测，机械归一端到端仅 57.6%。③证据 2 的 17.2% 是「检索注入 QA」口径，不可与证据 1 的 hit@10 混读成同一量。④被引的第三方报告本身含批评面：据该报告，99.8% 主要由中文摘要层挣得（去英文处理层 hit@10 反为 100.0%），英文归一化组件自身端到端为 81.0%，且报告的若干对照臂第三方不可复现（英文原题不入库）。本子站未独立复算该报告。⑤全部转引读数取自公开文档，非本机跑该插件所得。⑥版本面锚在不可变 tag v0.8.1 的 package.json（快照 review/evidence/dsh-memory.package.json），不再锚可变的 main——上游已被证实在不升版本号的情况下会改内容。⑦证据 4 是本机复跑，但它证明的是本记录的证据链在本机成立（快照 sha256、版本面版本、逐字引文按字节命中），不证明该插件的运行时行为。⑧可验证性的口径：本站把「可验证性」读作该插件本身可被第三方复跑的程度，不是本站证据链的自证程度——故 5 级只认「本机复跑该插件自己的运行入口」；本条的本机复跑（证据 4）是本站证据链探针，只支撑 4 级。

未测项（未测 ＋ 原因）

未测 ＋ 原因：①本机未跑该插件自己的检索侧基准（python -m md_cg.run_tests／python -m md_cg.bench_locomo_zh_public）：该插件本机未安装，且 dsh-memory 是纯 Python 包、本轮未把该仓源码离线取全（本机进程级出网不可用——直连 github.com／raw.githubusercontent.com 时 TLS 报 schannel SEC_E_NO_CREDENTIALS，review/evidence/ 下的快照是经 ghfast.top 镜像逐文件取回的 README 与 package.json），故上述基准读数只能取自公开文档原文（source 里给出 URL 与抓取日，review/evidence/ 落字节快照可离线核对）。证据 4 确是本机复跑，但它的射程只到「引证忠实 ＋ 版本面一致」，不等于跑过该插件。②「注入预算」未取得任何原始输出——README 未提供 token／字节用量读数（它有写入耗时一类的性能读数，但不属本维度），故该维度记 null、进 unmeasured_dims，不参与任何合计，不表示该插件预算控制差。③跨语言（非中英）检索未测。④第三方报告的对照臂未复现。⑤第三方可怎样复核运行时面（本站没做，但路径是明确的）：git clone https://github.com/FuRongJun-1999/dsh-memory → git checkout v0.8.1 → python -m md_cg.run_tests md_cg（README 自述该套件纯 stdlib；部分组需 Rust，可按组收窄）；公开基准另可 python -m md_cg.bench_locomo_zh_public，但它要读 data/benchmarks/locomo-zh-500/——该目录不在 npm 包 files 里，必须用源码仓。本站把这份路径写出来，是为了让复核者不必猜；不等于本站跑过。
