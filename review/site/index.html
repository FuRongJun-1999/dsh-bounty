灵枢插件测评

首页榜单方法说明

这是什么

灵枢悬赏站的插件测评子站：把「某个插件到底行不行」拆成可复跑的读数——每条测评都给命令与原始输出，判定逐项可指回读数。

不涉资金：本子站只放可核验读数，不做排名激励、不涉任何支付／钱包／链上概念。本子站的测评分（每维 1–5，总分 ≤ 25）是本子站自己的读数刻度，与 scripts/bounty_board.py 的悬赏声誉分（easy 1 ／ medium 3 ／ hard 6 ／ expert 10）不是同一个量，两者不可换算、不可相加。悬赏侧口径真源见 docs/bounty/README.md §四。

怎么读表

  1. 先看 榜单：总分 = 五个维度各自 1–5 分求和（≤ 25）。
  2. 再点进测评详情：维度表 ＋ 每条证据的命令与原始输出 ＋ 结论 ＋ 边界。
  3. 凡未取得读数的项，在「未测」节显式写「未测 ＋ 原因」——不要把它读成 0 分。
  4. 想看口径怎么定的，去 方法说明。

引用纪律

  • 每条证据必须写清 命令 ＋ 原始输出 ＋ 来源：三项缺一，生成器直接 fail-closed 拒绝出站。
  • 证据**分两档**，逐条在详情页顶部标出：本机复跑（由具名探针跑出，输出被 evidence_check.py --repro 逐字节复算）与 公开文档转引（取自公开文档原文读数，来源里给出 URL 与抓取日期——不得被读成本站本机重跑）。
  • **每条记录至少 1 条「本机复跑」**——只靠转引不算「命令 ＋ 原始输出」。这条由生成器强制。

复现步骤

项内容
环境Python 3.12（与同仓其他脚本一致；python -X utf8 走 UTF-8）。
依赖零第三方依赖——只用 Python 标准库（argparse／html／json／os／re／sys）。
生成python -X utf8 scripts/review_build.py（写 review/site/）。
守卫python -X utf8 tests/test_review_build.py（末行「通过 N / 失败 0」）。
变异python -X utf8 tests/test_review_build.py --mutate（逐条恰好命中期望红项）。
预期耗时生成 < 1 秒；守卫 < 5 秒；变异自证（逐条重跑守卫）< 60 秒。
不触网以上命令全程不发网络请求；CI 里同样成立。
