结论

值得用（平台型）：本机 0.25.0 已实装且在工具面留下 1 个可核验成本点（sidebar_open 324 tok/轮）；它的价值主面在客户端（0 tok），工具面数字不能代表其收益。生态装前必查 peer——0.x 的 caret 区间太窄，升级侧边栏即甩掉旧插件。

边界（本站不知道什么）

  • peer 兼容性是快照：87 个包的数字来自 2026-10-12 的 npm 全量扫 + 实测，未在本轮（2026-10-13）重扫，npm 侧新增/下架不可见。
  • web profile 现装 0.22.1（~/.dsh/profiles/web/package.json 现读），与本文取用的 desktop 0.25.0 不同——按 audit 文档的 desktop/web 并列口径处理，不视为异常。
  • 客户端插件不注册模型工具 ⇒ 工具面统计看不见它的使用率；本站不声称其「在用/没用」。
